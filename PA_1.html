Как пользоваться

Сначала пройди тест, затем открой нужную задачу. Для каждой задачи доступны исходное условие, готовое решение, копирование кода, подробный разбор строк, тестовые примеры и мини-лаборатория прямо в браузере.

Важно о демонстрациях

Встроенные мини-лаборатории воспроизводят логику задач на JavaScript — они не запускают Python. Скопированный код запускай в Python 3. Все проверки выполняй только на тестовых или согласованных системах.

⌘ Python · фрагмент для самостоятельной проверки

from collections import Counter
events = ["OK", "FAIL", "FAIL", "BLOCKED", "FAIL"]
c = Counter(events)
print("Ошибок:", c["FAIL"])
print("Блокировок:", c["BLOCKED"])
Ожидаемый результат: Ошибок: 3 Блокировок: 1

Код запускается в Python 3 и использует только стандартную библиотеку. Эксперименты выполняйте на учебных данных и в разрешённом окружении.
