01 / Основы

Как Python хранит данные

Выбор структуры влияет не только на синтаксис, но и на скорость анализа больших объёмов событий.

[ ]

Список · list

Упорядоченная изменяемая последовательность. Удобен для последовательного хранения журналов и матриц. Доступ по индексу обычно O(1), поиск значения по всему списку O(n).

events = ['LOGIN', 'FAIL', 'LOGIN']
print(events[0])  # LOGIN
( )

Кортеж · tuple

Упорядоченная неизменяемая последовательность. Хорошо описывает запись фиксированного формата: источник, серьёзность, сообщение.

event = ('firewall', 'HIGH', 'blocked')
print(event[1])   # HIGH
{ : }

Словарь · dict

Отображение «ключ → значение». Например, IP → количество блокировок. Доступ по ключу в среднем O(1).

blocks = {'10.0.0.5': 2}
blocks['10.0.0.5'] += 1
{ }

Множество · set

Хранит только уникальные значения, порядок элементов не гарантирован. Проверка принадлежности обычно O(1). Подходит для чёрных списков и баз индикаторов.

blacklist = {'10.0.0.5', '8.8.8.8'}
print('8.8.8.8' in blacklist)  # True

Сквозной алгоритм анализа событий

Строка журналаivan FAIL
→
Разбор строкиinput().split()
→
Проверкаstatus == 'FAIL'
→
Словарь{'ivan': 2}

Фундаментальный паттерн: прочитать → разобрать → проверить условие → обновить структуру → вывести результат. Он повторяется почти во всех упражнениях занятия.

get() против отсутствующего ключа

Выражение counts[user] вызовет KeyError, если пользователя ещё нет. Метод get(user, 0) берёт текущее значение, а если ключ отсутствует — возвращает ноль.

counts = {}
counts['ivan'] = counts.get('ivan', 0) + 1
counts['ivan'] = counts.get('ivan', 0) + 1
print(counts) # {'ivan': 2}

Почему важен split(maxsplit=2)

Строка firewall HIGH blocked external connection содержит три логических поля, последнее — из нескольких слов. Обычный split() создаст четыре элемента, а ограничение числа разбиений сохранит всё сообщение целиком.

line = 'firewall HIGH blocked external connection'
source, level, msg = line.split(maxsplit=2)
# msg == 'blocked external connection'

Хеш-таблица и коллизии

В dict и set хеш помогает быстро найти место хранения объекта. Если разные ключи приводят к одинаковому хешу, возникает коллизия. Python дополнительно сравнивает ключи, чтобы их различить.

Худший случай при множестве коллизий может быть значительно медленнее среднего O(1).

Bloom filter · фильтр Блума

Вероятностная структура, позволяющая очень компактно проверять, мог ли элемент встречаться. «Точно не было» — надёжный отрицательный ответ при обычной модели без удаления; «возможно, было» потребует точной проверки.

Это не шифрование и не хранилище исходных адресов: возможны ложноположительные срабатывания.

Отдельно: триада CIA

ConfidentialityКонфиденциальность: данные видят только уполномоченные лица
IntegrityЦелостность: данные не подменены незаметно
AvailabilityДоступность: системы и данные доступны вовремя

Количество основных свойств — 3; они встречаются во втором тесте.

▣ Ситуация из практики

В Сигнал поступили строки из журнала входа, часть из них содержит некорректные IP. Прежде чем строить отчёт, данные надо проверить.

Актив: Сетевой журнал. Угроза: Подозрительные адреса.

◉ Разбираем причинно-следственную связь

Библиотека ipaddress умеет разбирать IPv4 и IPv6. Проверка адреса необходима до группировки, но сам по себе частый IP не доказывает, что это злоумышленник.

Что проверяем: Отделить факт от гипотезы.

⌘ Python · фрагмент для самостоятельной проверки

from collections import Counter
import ipaddress
raw = ["192.0.2.7", "wrong", "192.0.2.7", "2001:db8::1"]
valid = []
for item in raw:
    try:
        valid.append(str(ipaddress.ip_address(item)))
    except ValueError:
        pass
print(sorted(Counter(valid).items()))
Ожидаемый результат: [('192.0.2.7', 2), ('2001:db8::1', 1)]

Код запускается в Python 3 и использует только стандартную библиотеку. Эксперименты выполняйте на учебных данных и в разрешённом окружении.
