ТЕМА 1 · ОСНОВЫ PYTHON

Типы данных: у каждого значения своя роль

Число, строка и список могут выглядеть похоже — но Python обрабатывает их по-разному.

АНАЛОГИЯ

Переменная — это имя, связанное с объектом

Представьте набор подписанных контейнеров. В одном лежит целое число 42, в другом — текст "42", в третьем — список чисел. Имя переменной указывает на значение; его тип определяет доступные операции. В Python имя не «приклеено» навсегда к одному типу.

PYTHON-ПРИМЕР
value = 42
Целое число: подходит для подсчёта учеников, попыток и шагов.
РЕЗУЛЬТАТ type(value)
<class 'int'>

Нажимайте на карточки, чтобы менять пример; значения заранее заданы для демонстрации.

Четыре типа из задания

ТипПримерДля чего
int25Целые числа и счётчики
float25.5Числа с дробной частью
str"25"Текст, даже если в нём цифры
list[25, 26]Упорядоченная коллекция значений

Почему правильный ответ — int?

Слово integer означает целое число. int хранит, например, -7, 0, 2026. float хранит числа с плавающей точкой, str — строки, а list — коллекции.

Запомните: 42 и "42" — разные значения. Первое можно складывать как число, второе — соединять как текст.

Попробуйте сравнить сложение чисел и строк

types_demo.py
a = 10
b = 5
print(a + b)              # 15

text_a = "10"
text_b = "5"
print(text_a + text_b)    # 105

number = int("10")       # строка → целое число
print(number + 5)         # 15
print(type(number))      # <class 'int'>
Подводный камень: int("12") работает, а int("привет") вызывает ValueError. Преобразовывать в число можно лишь подходящий текст.

ТЕМА 2 · АЛГОРИТМЫ

Цикл while: повторяем, пока условие истинно

Вместо того чтобы писать одну команду много раз, задаём условие продолжения.

ПОНЯТНО НА ПРИМЕРЕ

Пока горит зелёный — продолжай движение

Компьютер проверяет условие. Если оно True, выполняет тело цикла и возвращается к проверке. Когда условие впервые становится False, цикл заканчивается.

while_demo.py
counter = 1

while counter <= 3:
    print("Шаг", counter)
    counter += 1

print("Готово!")

Ожидаемый вывод: Шаг 1, Шаг 2, Шаг 3, Готово!

Визуальная блок-схема

Подсветка меняется при нажатии «Следующий шаг».

ИНТЕРАКТИВНЫЙ ТРЕНАЖЁР

Пройдите цикл по шагам

Измените число повторений, затем нажимайте «Следующий шаг». Визуализатор показывает, на каком этапе находится алгоритм.

Здесь появится вывод программы…
Ожидает запуска
1. Проверка counter <= N
2. Вывод текущего значения counter
3. Увеличение счётчика на 1
4. Условие ложно — выход из цикла

while и for — в чём разница?

while применяют, когда повторение определяется условием: «пока число меньше порога». for удобно использовать при переборе элементов или заданного диапазона.

while_vs_for.py
# Один и тот же результат: 1, 2, 3
n = 1
while n <= 3:
    print(n)
    n += 1

for n in range(1, 4):
    print(n)

А если не изменить счётчик?

Если counter постоянно равен 1, проверка counter <= 3 всегда даёт True. Получаем бесконечный цикл.

Антипример: цикл без counter += 1 не завершится сам. В терминале его обычно останавливают клавишами Ctrl + C.

Три детали синтаксиса: после условия ставится двоеточие :; тело цикла пишется с отступом; условие проверяется перед каждой итерацией.

ТЕМА 3 · ОРГАНИЗАЦИЯ ПРОЕКТА

venv: отдельное окружение для каждого проекта

Два проекта могут требовать разные версии библиотек. Виртуальное окружение помогает не смешивать зависимости.

ИНТЕРАКТИВНАЯ СХЕМА

Что произойдёт без изоляции и с ней?

Проект A · бот

requests 2.x Общий Python
main.py

Проект B · сайт

requests 3.x Общий Python
app.py
Оба проекта используют общую установку. Несовместимые требования к версии одной библиотеки могут привести к конфликту.

Что на самом деле означает venv?

venv — модуль стандартной библиотеки Python для создания виртуальных окружений. Он создаёт каталог с собственным интерпретатором Python и областью для устанавливаемых пакетов.

Имя .venv — распространённое соглашение для папки окружения. Оно не обязательно: можно назвать каталог env или иначе.

А что делают Git и pip?

  • Git отслеживает версии исходного кода.
  • pip устанавливает и управляет Python-пакетами.
  • venv создаёт изолированное окружение.
  • SAST — статический анализ безопасности кода, не окружение.

Создаём окружение: пошаговый сценарий

Команда из контрольного задания: python -m venv .venv. Аргумент -m означает «запусти модуль», а .venv — имя создаваемой папки.

PowerShell · команды терминала
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install requests
python -m pip list
deactivate

Если команда python не найдена в Windows, попробуйте py -m venv .venv. В некоторых Linux/macOS команда называется python3. PowerShell иногда ограничивает выполнение скриптов; при таком сообщении можно использовать cmd или запускать интерпретатор окружения по полному пути без активации.

Создание: Python формирует папку .venv с необходимыми файлами окружения. Активация для этого не нужна.

Как выглядит папка проекта?

my_project/ ├── .venv/ ← окружение │ ├── Scripts/ (Windows) │ └── Lib/ ├── main.py ← программа ├── requirements.txt ← зависимости ├── .env ← настройки └── .gitignore ← исключения Git

На Linux/macOS вместо Scripts/ обычно используется bin/. Структура окружения зависит от ОС.

Как перенести зависимости на другой ПК?

Обычно саму папку .venv не копируют в Git — окружение пересоздают, а пакеты устанавливают по списку.

requirements workflow
# Сохранить список пакетов
python -m pip freeze > requirements.txt

# На другом компьютере:
python -m venv .venv
# Активировать окружение
python -m pip install -r requirements.txt

Команды со знаком # здесь — комментарии для терминала. В реальном проекте не забывайте сначала активировать новое окружение или использовать его интерпретатор явно.

ТЕМА 4 · КОНФИГУРАЦИЯ

.env — файл настроек, а не виртуальное окружение

Названия похожи, но их назначение абсолютно разное. Это важный нюанс контрольного задания.

.venv/
ПАПКА
  • Создаётся модулем venv.
  • Содержит Python и установленные пакеты.
  • Изолирует зависимости разных проектов.
  • Обычно исключается из Git.
.env
ФАЙЛ
  • Содержит пары КЛЮЧ=значение.
  • Хранит настройки запуска приложения.
  • Читается специальным кодом или инструментом.
  • При наличии секретов исключается из Git.

Пример конфигурации

.env
APP_NAME=StudyBot
DEBUG=false
MAX_ATTEMPTS=3
API_TOKEN=replace_me_locally
Не вставляйте сюда реальные ключи. replace_me_locally — заглушка, а не секрет. Если .env содержит пароли или токены, не загружайте его на GitHub. Секреты в примерах и демонстрациях не нужны.
config_demo.py
import os
from dotenv import load_dotenv

load_dotenv()  # загрузить .env

app_name = os.getenv("APP_NAME", "MyApp")
max_attempts = int(os.getenv("MAX_ATTEMPTS", "3"))

print(app_name)
print(max_attempts)

Библиотеку нужно установить отдельно: python -m pip install python-dotenv. Обычный Python не загружает файл .env автоматически.

Ещё один нюанс: значения из переменных окружения приходят в Python как str. Поэтому MAX_ATTEMPTS=3 читается через os.getenv() как строка "3"; для числового счётчика используем int(...).

Защитите файлы с настройками

.gitignore
# Локальное окружение
.venv/

# Локальная конфигурация и секреты
.env

# Временные файлы Python
__pycache__/
*.pyc

Для совместной работы создайте отдельный .env.example только с названиями переменных и безопасными заглушками.

Откуда берутся настройки?

Файл
.env
→
load_dotenv()
→
os.getenv()

Это один из способов работы с конфигурацией. В системах развёртывания переменные окружения часто задаются напрямую, без файла .env.

По умолчанию python-dotenv не перезаписывает уже заданные переменные окружения.

ПРАКТИКУМ · ОБЪЕДИНЯЕМ ЗНАНИЯ

Мини-проект «Счётчик учебных шагов»

Создадим небольшой проект, в котором есть окружение, настройка количества повторов, целочисленный тип и цикл while.

Чек-лист выполнения

Отмечайте каждый шаг после выполнения на компьютере.

0 из 7 шагов

Шаг 1. Создайте проект

Терминал · Windows PowerShell
mkdir lesson4_project
cd lesson4_project
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install python-dotenv

Если используете macOS/Linux, замените строку активации на source .venv/bin/activate, а при необходимости используйте python3 вместо python.

Шаг 2. Создайте файл .env

Это количество итераций, которое будет прочитано программой.

.env
TARGET_COUNT=3
Попробуйте затем поменять 3 на 5 и запустить программу снова.

Шаг 3. Создайте main.py

main.py
import os
from dotenv import load_dotenv

load_dotenv()

limit = int(os.getenv("TARGET_COUNT", "3"))
step = 1

while step <= limit:
    print(f"Учебный шаг {step} из {limit}")
    step += 1

print("Все шаги выполнены!")

Шаг 4. Запустите и объясните результат

Терминал
python main.py
> python main.py Учебный шаг 1 из 3 Учебный шаг 2 из 3 Учебный шаг 3 из 3 Все шаги выполнены!
  1. load_dotenv() делает настройки из файла доступными программе.
  2. os.getenv(...) берёт число повторов как строку.
  3. int(...) преобразует строку в целое число.
  4. while выводит строки, пока step <= limit.
  5. step += 1 приближает выход из цикла.
Проверка ошибок: если в .env поставить TARGET_COUNT=три, преобразование int(...) вызовет ValueError. Для пользовательского ввода применяют обработку ошибок через try/except.

ОШИБКИ И ДИАГНОСТИКА

Типичные затруднения

Не только что написать, но и как быстро разобраться, если код не заработал.

«Почему 10 + 5 стало 105?»

Потому что обе переменные были строками: "10" + "5" объединяет текст. Преобразуйте их с помощью int().

fix_str.py
a, b = "10", "5"
print(int(a) + int(b))  # 15

«Цикл завис — что делать?»

Проверьте, может ли условие стать ложным. Есть ли изменение counter внутри тела? Верно ли стоит знак <=?

fix_while.py
counter = 1
while counter <= 3:
    print(counter)
    counter += 1  # важно!

«Модуль не найден»

Возможно, пакет установлен в другом окружении. Проверьте активное окружение, команду python -m pip show python-dotenv и выбранный интерпретатор Python в IDE.

При работе без активации можно явно использовать .venv\Scripts\python.exe (Windows) или .venv/bin/python (Linux/macOS).

«.env не читается»

Убедитесь, что файл действительно называется .env, а не .env.txt, что библиотека установлена и вызвано load_dotenv(). При нестандартном расположении файла укажите путь явно.

Файлы .env не загружаются интерпретатором автоматически — это поведение библиотеки или вашей программы.

Вопрос 1
01

Какой тип данных используется для целых чисел?

Ответ: int. Integer — целое число. float представляет числа с дробной частью, str — текст, list — список. Пример: type(25) возвращает <class 'int'>.
Вопрос 2
02

Как называется изолированное окружение Python-проекта?

Ответ: venv. Модуль создаёт отдельную среду с Python и зависимостями. pip устанавливает пакеты, а Git сохраняет историю исходного кода. Точнее, venv — инструмент создания виртуальных окружений, а имя папки может быть .venv.
Вопрос 3
03

Какой цикл выполняется, пока условие истинно?

Ответ: while. Он проверяет условие перед каждой итерацией. for перебирает элементы и значения диапазона; if — условное ветвление, def — объявление функции.
Вопрос 4
04

Какая команда создаёт виртуальное окружение .venv?

Ответ: python -m venv .venv. python запускает интерпретатор, -m venv запускает стандартный модуль, а .venv задаёт каталог нового окружения.
Вопрос 5
05

Как называется файл для хранения переменных окружения?

Формат ответа: одно слово латинскими строчными буквами без пробелов, впереди слова — знак.

Ответ: .env. Имя начинается с точки. В формате файла обычно используются строки вроде APP_MODE=dev. Не путайте с папкой .venv; значения из .env нужно загрузить самостоятельно, например через python-dotenv.

Задача A. Что выведет Python?

ТИПЫ

Условие: определите две строки вывода, не запуская программу.

task_a.py
x = "7"
y = 2
print(x * y)
print(int(x) * y)
Показать ответ и объяснение

Ответ: первая строка — 77, вторая — 14. Умножение строки на целое число повторяет строку; после int("7") происходит обычное арифметическое умножение.

Задача B. Посчитайте итерации

WHILE

Условие: сколько раз выполнится print()?

task_b.py
n = 2
while n < 10:
    print(n)
    n += 3
Показать ответ и объяснение

Ответ: три раза. Будут напечатаны 2, 5, 8. Затем n станет равно 11, условие 11 < 10 станет ложным.

Задача C. Найдите ошибку

ОКРУЖЕНИЕ

Условие: ученик создал .venv, но в нём не появился пакет requests. Как проверить, куда он устанавливается?

Показать ответ и объяснение

Проверьте, что в IDE выбран интерпретатор из .venv. Используйте python -m pip --version и python -m pip show requests. При необходимости запускайте Python прямо из созданного окружения — это исключает путаницу между несколькими установками.

Проверка (из активированного окружения)
python -m pip --version
python -m pip show requests

Задача D. Настройка из .env

КОМБИНИРОВАННАЯ

Условие: в .env записано MAX_STEPS=4. Напишите код, который считает значение, преобразует в число и напечатает шаги от 1 до 4.

Показать пример решения и объяснение
solution_d.py
import os
from dotenv import load_dotenv
load_dotenv()

maximum = int(os.getenv("MAX_STEPS", "4"))
step = 1
while step <= maximum:
    print(step)
    step += 1

Разбор: os.getenv даёт строковое значение, int делает число, а while повторяет вывод до верхней границы.
