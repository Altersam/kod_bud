# Развёртывание модуля 1

Рекомендуемый способ: распаковать ZIP, затем загрузить HTML непосредственно в корень репозитория. **Не создавать папку `/module1` или `/lessons`: относительные ссылки ожидают размещение в корне.**

`AI_img.html` и `AI_kanban.html` — дополнительные материалы. Их исходное содержимое оставлено без изменений.

## По желанию: восстановление полных оригиналов уроков 7–9

Перед загрузкой файлов выполнить в папке с распакованным архивом `python restore_originals.py`. В результате три оригинальных занятия из GitHub будут восстановлены по зафиксированным хешам, сохранится также бывшая главная страница, а сборщик добавит единый слой навигации.

## GitHub Actions

В архив входит `.github/workflows/rebuild_module1.yml`. Если загрузить workflow в GitHub, можно вручную запустить «Rebuild module 1» и пересобрать страницы по тому же шаблону. Права GitHub Actions на запись должны быть разрешены в настройках репозитория.

## Навигация

`index.html` → уроки 1–14 → `PA_1.html` → `index.html`. На страницах есть кнопки «Оглавление», «Назад» и «Вперёд». Все ссылки относительные, поэтому курс можно развернуть в корне GitHub Pages-проекта.
