Ответы на первые 5 вопросов

1. Какая структура данных обеспечивает O(1) среднее время поиска элемента?
✓
Словарь (dict)
Словарь реализован на основе хеш-таблицы. По ключу Python в среднем находит значение за константное время.
2. Для чего используется Bloom filter в задачах ИБ?
✓
Для быстрой проверки принадлежности
Bloom filter — вероятностная структура: он очень быстро отвечает, мог ли элемент встречаться ранее. Возможны ложноположительные ответы, но ложноотрицательных при корректной реализации нет.
3. Что такое хэш-коллизия?
✓
Одинаковый хэш для разных данных
Количество возможных входных данных больше количества возможных хэш-значений, поэтому теоретически разные данные могут дать одинаковый результат хеширования.
4. Какая структура наиболее эффективна для хранения IP-адресов в чёрном списке?
✓
Множество (set)
Повторы не нужны, а проверка ip in blacklist выполняется в среднем за O(1).
5. Какова средняя сложность поиска в BST и чему равно основание логарифма?
✓
O(log N), основание — 2
При сбалансированном бинарном дереве на каждом шаге отбрасывается примерно половина оставшихся вариантов. В асимптотике основание логарифма обычно не указывают, но в вопросе LMS требуется именно 2.
Тренажёр кода 1

Подсчёт неуспешных попыток входа

Идея решения

Нужно прочитать N записей username status и посчитать только статусы FAIL. Ключ словаря — имя пользователя, значение — число неудачных входов.

Считать количество строк.
Создать пустой словарь fails = {}.
Разбить каждую строку на username и status.
Если статус FAIL, увеличить счётчик пользователя.
Вывести словарь.

Готовый код для LMS

n = int(input())

fails = {}

for _ in range(n):
    username, status = input().split()

    if status == "FAIL":
        fails[username] = fails.get(username, 0) + 1

print(fails)

Ключевая строка

fails[username] = fails.get(username, 0) + 1

get(username, 0) означает: «возьми текущее значение, а если такого ключа ещё нет — считай, что там 0».

Тренажёр кода 2

Чёрный список IP-адресов

Почему два множества?

blacklist хранит запрещённые IP. found хранит только уникальные IP из журнала, которые обнаружены в blacklist. Поэтому один и тот же адрес, встретившийся 10 раз, увеличит результат только на 1.

n = int(input())

blacklist = set()

for _ in range(n):
    blacklist.add(input())

m = int(input())

found = set()

for _ in range(m):
    ip = input()

    if ip in blacklist:
        found.add(ip)

print(len(found))
Важно: если использовать обычный счётчик вместо found = set(), повторный адрес из журнала будет учитываться несколько раз, а по условию нужны именно уникальные IP.
Тренажёр кода 3

Есть ли число в наборе?

Здесь проверяется выбор структуры данных для membership test. Множество подходит лучше списка, когда основная операция — много раз спрашивать «есть ли элемент?».

n = int(input())

numbers = set()

for _ in range(n):
    numbers.add(int(input()))

x = int(input())

if x in numbers:
    print("FOUND")
else:
    print("NOT FOUND")
✓
x in numbers — ключевая операция. Для set она выполняется в среднем за O(1).
Тренажёр кода 4

Частотный анализ текста журнала

Что требуется

Посчитать только английские буквы без учёта регистра, игнорировать пробелы, цифры и знаки, затем вывести найденные буквы по алфавиту.

text = input().lower()

freq = {}

for ch in text:
    if 'a' <= ch <= 'z':
        freq[ch] = freq.get(ch, 0) + 1

for ch in sorted(freq):
    print(ch, freq[ch])

Почему .lower()?

Чтобы H и h считались одной буквой.

Почему sorted(freq)?

Сортируется последовательность ключей словаря, поэтому вывод идёт по алфавиту.

Тренажёр кода 5

Матрица нагрузок узлов

Задача

Найти максимальный элемент матрицы, определить строку его первого появления и поменять эту строку местами с первой.

n = int(input())
m = int(input())

matrix = []

for _ in range(n):
    row = list(map(int, input().split()))
    matrix.append(row)

max_value = matrix[0][0]
max_row = 0

for i in range(n):
    for j in range(m):
        if matrix[i][j] > max_value:
            max_value = matrix[i][j]
            max_row = i

matrix[0], matrix[max_row] = matrix[max_row], matrix[0]

for row in matrix:
    print(*row)
Почему именно >, а не >=? Потому что условие требует первое вхождение максимума. При равенстве max_row не меняется.

Самостоятельная работа 1

Фильтрация критичных событий

Каждое событие имеет три поля: source, severity, message. События собираются в список, а каждое отдельное событие хранится как кортеж.

Пример:
firewall HIGH blocked external connection
→
("firewall", "HIGH", "blocked external connection")
n = int(input())

events = []

for _ in range(n):
    source, severity, message = input().split(maxsplit=2)
    events.append((source, severity, message))

critical_level = input()

found = False

for source, severity, message in events:
    if severity == critical_level:
        print(f"[CRITICAL] {source}: {message}")
        found = True

if not found:
    print("Нет критичных событий")

Confidentiality

Конфиденциальность. Данные доступны только тем, кому разрешено.

Примеры: 2FA, шифрование, разграничение доступа, VPN.

Integrity

Целостность. Данные не должны быть незаметно подменены.

Примеры: электронная подпись, хэш-суммы, контроль изменений.

Availability

Доступность. Система и данные должны оставаться доступными.

Примеры: резервирование, отказоустойчивость, защита от DDoS.
