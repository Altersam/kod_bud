02 · Тренажёр 1

Словарь как счётчик неудачных входов

Задача: для каждой строки вида username status увеличить счётчик только если статус равен FAIL.

n = int(input())

fails = {}

for _ in range(n):
    username, status = input().split()

    if status == "FAIL":
        fails[username] = fails.get(username, 0) + 1

print(fails)

Почему здесь нужен dict?

Имя пользователя становится ключом, а число ошибок — значением. Метод get(username, 0) возвращает текущий счётчик или 0, если ключ встретился впервые.

O(1)
средний доступ к ключу словаря

04 · Тренажёр 4

Частотный анализ текста

Преобразуем текст к нижнему регистру, пропускаем всё кроме a..z, а словарь используем как набор счётчиков.

text = input().lower()

freq = {}

for ch in text:
    if 'a' <= ch <= 'z':
        freq[ch] = freq.get(ch, 0) + 1

for ch in sorted(freq):
    print(ch, freq[ch])

Сравнение 'a' <= ch <= 'z' работает благодаря порядку кодовых точек символов.

05 · Тренажёр 5

Матрица нагрузок: найти максимум и поднять строку вверх

n = int(input())
m = int(input())

matrix = []

for _ in range(n):
    row = list(map(int, input().split()))
    matrix.append(row)

max_value = matrix[0][0]
max_row = 0

for i in range(n):
    for j in range(m):
        if matrix[i][j] > max_value:
            max_value = matrix[i][j]
            max_row = i

matrix[0], matrix[max_row] = matrix[max_row], matrix[0]

for row in matrix:
    print(*row)

Что важно

1. Матрица — это список строк, где каждая строка тоже список.

2. Два вложенных цикла дают просмотр всех ячеек.

3. Обмен строк в Python можно выполнить одной операцией.

сложность O(n·m)

06 · Самостоятельная

События безопасности: list + tuple + split(maxsplit=2)

n = int(input())

events = []

for _ in range(n):
    source, severity, message = input().split(maxsplit=2)
    events.append((source, severity, message))

critical_level = input()
found = False

for source, severity, message in events:
    if severity == critical_level:
        print(f"[CRITICAL] {source}: {message}")
        found = True

if not found:
    print("Нет критичных событий")

Зачем maxsplit=2?

Чтобы сообщение после второго пробела осталось целиком. Например, firewall HIGH blocked external connection превращается ровно в три поля.

("firewall", "HIGH", "blocked external connection")

Что выбрать?

Нужен порядок и изменение → list. Нужен быстрый доступ по имени/ID → dict. Нужны уникальные значения и проверка принадлежности → set. Нужна фиксированная запись из полей → tuple.
