Важный момент из твоей ошибки

Правильно:

def __init__(self, secret):
    self.__secret = secret

Неправильно:

def __inti__(self, secret):
    ...

def inti(self, secret):
    ...

def _init_(self, secret):
    ...

02Три конструкции, которые нужны почти во всех заданиях

1. Конструктор 
def __init__(self, value):
    ...

Он вызывается при создании объекта.

2. self 
self.__secret = secret

self указывает на конкретный объект.

3. Внутренний атрибут 
self.__secret

Двойное подчёркивание включает name mangling.

03Логика инкапсуляции

Внешнему коду обычно не требуется знать секрет. Ему требуется только выполнить разрешённую операцию.

1
Получаем значение
Например, PIN, пароль, API-токен.
2
Храним внутри
self.__token
3
Работаем через метод
check() или masked()
4
Возвращаем результат
ACCESS, True, ******, длину и т. д.

06Вводные тренажёры

Тренажёр 1 — SecretValue

Секрет хранится внутри объекта. Метод всегда возвращает ровно шесть звёздочек.

✓ класс называется SecretValue
✓ конструктор: __init__
✓ внутренний атрибут: __secret
✓ маска: ******
Решение
Скопировано 
class SecretValue:
    def __init__(self, secret):
        # Сохраняем секрет внутри объекта.
        self.__secret = secret

    def get_masked(self):
        # Исходный секрет наружу не выдаём.
        # По условию возвращаем ровно 6 звёздочек.
        return "******"

Тренажёр 2 — PasswordVault

Пароль хранится внутри объекта, а наружу доступен только метод проверки.

Решение
Скопировано 
class PasswordVault:
    def __init__(self, password):
        # Сохраняем пароль во внутреннем атрибуте.
        self.__password = password

    def check_password(self, value):
        # Сам пароль не возвращается.
        if value == self.__password:
            return "ACCESS"

        return "DENIED"

09Итоги урока

Главные идеи

  • данные хранятся внутри объекта;
  • работа идёт через методы;
  • секрет не раскрывается без необходимости;
  • можно вернуть маску, длину, статус или True/False;
  • изменения выполняются по контролируемому правилу.

Не забывать

  • __init__ — это init;
  • self обязателен в методах экземпляра;
  • маскирование не является шифрованием;
  • __attr не делает секрет абсолютно недоступным;
  • возвращать настоящий пароль наружу обычно не нужно.
