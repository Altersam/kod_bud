# kod_bud — интерактивный конспект занятия

Готовый одностраничный сайт для GitHub Pages.

## Что внутри

- объяснение `list`, `dict`, `set`, `tuple`;
- интерактивные визуализаторы;
- пошаговый разбор словаря-счётчика;
- blacklist IP на множестве;
- анализ частот букв;
- матрица нагрузок;
- фильтрация событий безопасности;
- Bloom filter (учебная визуализация);
- демонстрация хэш-коллизии;
- визуальный поиск по BST;
- блок CIA triad;
- мини-тест;
- кнопки копирования кода.

## Публикация

1. Положите `index.html` в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, folder: `/ (root)`.
5. Сайт откроется по адресу вашего GitHub Pages-репозитория.
