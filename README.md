# Код будущего · Модуль 1 · Python × Кибербезопасность

**Полный курс: 14 занятий + промежуточная аттестация (занятие 15).** Страницы работают на GitHub Pages без сборщика и без внешних JS-библиотек.

## Быстрая публикация

1. Распакуйте архив.
2. Загрузите файлы `index.html`, `lesson_1.html` … `lesson_14.html`, `PA_1.html`, `AI_img.html`, `AI_kanban.html` **в корень** `Altersam/kod_bud`. Вложенных папок с HTML нет.
3. GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Сайт: <https://altersam.github.io/kod_bud/>.

## Состав

| Файлы | Назначение |
| --- | --- |
| `index.html` | Главный каталог: схема курса, поиск, фильтры, прогресс 15 занятий, ссылки. |
| `lesson_1.html`–`lesson_6.html` | Основы ИБ, право, Python, безопасная среда и коллекции. |
| `lesson_7.html`–`lesson_10.html` | ООП, инкапсуляция, валидация, полномочия и аудит. |
| `lesson_11.html`–`lesson_14.html` | Криптографическая случайность, байты, анализ токенов, аудит генератора паролей. |
| `PA_1.html` | Промежуточная аттестация 1-го модуля, **15-е занятие**. |
| `AI_img.html`, `AI_kanban.html` | Самостоятельные дополнительные материалы, оставлены в корне, содержимое не изменялось. |

Единая линия: «Сигнал» — учебная цифровая платформа. На каждом шаге применяется модель **защищаемый актив → угроза → наблюдаемый сигнал → контроль → проверка**. Новый блок добавляет визуальную схему, практику Python, разбор типичной ошибки, вопросы с объяснением, проверенные источники, кнопку копирования и отметку прохождения.

### Важное примечание о происхождении исходных материалов

Оригиналы уроков **1–6 и 10–14**, а также `PA_1.html` получены из файлов пользователя или репозитория и обогащены без удаления основного учебного содержания.

Оригиналы уроков **7–9** есть на GitHub, но текущая среда позволила проверить их структуру и содержание, **не позволив выгрузить исходные байты в локальный архив**. Чтобы архив был самодостаточным, вложены новые подробные самостоятельные версии 7–9 по тем же темам (ООП, инкапсуляция, Mass Assignment, авторизация). Они содержат лабораторные примеры, решения, самопроверку, схемы и навигацию, **но не являются побайтовыми копиями оригиналов**.

Если нужно обязательно сохранить полный исходный материал уроков 7–9, после распаковки запустите `python restore_originals.py` на компьютере с доступом к GitHub. Скрипт проверяет SHA-1 исходных Git-объектов, возвращает **точные оригиналы** `lesson_7.html`–`lesson_9.html` и бывший `index.html` как `extra_structures_legacy.html`, затем добавляет единую навигацию и практику. Остальные файлы не перезаписываются исходниками. После этого загружайте получившиеся HTML в корень репозитория.

Пример:

```bash
python restore_originals.py
```

При отсутствии сети архив уже работает полностью, включая 7–9; восстановление оригиналов — дополнительная операция для максимальной сохранности авторских материалов.

## Управление и технические требования

- Интерактивность реализована обычным HTML, CSS, JS, SVG; картинки, код, ответы и ссылки доступны со страниц.
- Нет сборки Node.js и нет внешней CSS/JS-зависимости для навигации.
- Отметки прогресса хранятся **локально в браузере** (`localStorage`, ключи `kod_bud_v3_done_1`–`kod_bud_v3_done_15`), без персональной аналитики.
- `build_course.py` с `module1_extension.py` можно запустить повторно — блоки `KD_COURSE_*` будут заменены, а не продублированы.
- Обозначения «пройдено» не являются оценками за официальную промежуточную аттестацию: это самоотметка пользователя.
- Действия с настоящими системами выполняются только при наличии полномочий; учебные примеры используют тестовые данные.
